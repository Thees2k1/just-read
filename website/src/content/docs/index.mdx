## Release Benchmarks (`v0.1.0-alpha.1`)

Measured on a physical **Samsung Galaxy A34 (120Hz)** running the signed, R8-minified release APK:

| Metric | Value | Notes |
| :--- | :--- | :--- |
| **APK Size** | **1.55 MB** | R8-minified & resource-shrunk (includes 8-page Quick Guide PDF) |
| **Cold Start** | **484 – 639 ms** | `adb shell am start -W` cold launch to first frame |
| **Idle Memory (PSS)** | **~31.3 MB** | Lean baseline before PDF bitmap streaming |
